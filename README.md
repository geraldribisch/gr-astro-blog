# gr-astro-blog

Persönlicher Blog von Gerald Ribisch, gebaut mit [Astro](https://astro.build/) als statische Website.

Das Layout basiert auf dem Theme [Monograph](https://github.com/xocothemes/monograph) von Andrei Alba
(MIT-Lizenz, siehe [LICENSE-THEME.md](./LICENSE-THEME.md)). Hinweise zur Anpassung stehen in
[CUSTOMIZATION.md](./CUSTOMIZATION.md).

## Entwicklung

Voraussetzung: Node.js ab 22.12.

```bash
npm install
npm run dev
npm run build
```

- Beiträge: `src/content/posts/<slug>/index.md`
- Einstellungen, Navigation, Kategorien: `src/config/`
